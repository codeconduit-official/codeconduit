# Typography

All fonts are self-hosted in `assets/fonts/` (Latin subset, woff2). Each is licensed under the SIL Open Font License 1.1, which permits redistribution and commercial use.

- Instrument Serif (headlines): https://fonts.google.com/specimen/Instrument+Serif
- Inter (body and interface): https://fonts.google.com/specimen/Inter
- JetBrains Mono (labels): https://fonts.google.com/specimen/JetBrains+Mono

No third-party font requests are made. Georgia, system sans-serif, and system monospace are the fallbacks.
